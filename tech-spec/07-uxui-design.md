## Design Focus

**Desktop-first** — ออกแบบมาเพื่อการใช้งานบนจอ Monitor หรือ Laptop ประจำเคาน์เตอร์จุดรับเคลม โดยมีเป้าหมายหลักคือ:
- **Single Source of Truth**: รวมข้อมูลการติดตาม (Tracking) ไว้ในหน้าจอและตารางเดียว
- **Modal-based Workflow**: ใช้ระบบ Pop-up ควบคุมฟอร์มแบบกึ่งทึบแสง (Backdrop + Blur) เพื่อไม่ให้ลืมว่ากำลังจัดการข้อมูลแถวไหนอยู่
- **Interactive UI**: ปุ่มและแจ้งเตือนตอบสนองผู้ใช้แบบเรียลไทม์ พร้อมสีสันทิศทางเดียว (Green=ผ่าน, Red=ปัญหา)

## Tailwind Color Palette 

ระบบควบคุมโทนสีและอารมณ์ด้วยค่าของ CSS Tailwind:

```css
/* Core Colors */
bg-slate-50:  #f8fafc;   /* พื้นหลังหลักของ Application */
bg-white:     #ffffff;   /* พื้นหลังของกล่องตารางและ Component กรอบต่างๆ */
blue-600:     #2563eb;   /* สีปุ่ม Primary / เพิ่มงานใหม่ */
emerald-600:  #059669;   /* ปุ่ม Export Excel (ตระกูลออกรายงาน) */
slate-800:    #1e293b;   /* ตัวหนังสือ Heading/ชื่อหัวข้อ */
slate-500:    #64748b;   /* ตัวอักษรอธิบายเนื้อหา (Body) */

/* Status Badge Colors (แถบสถานะงาน) */
bg-yellow-100 & text-yellow-800   /* Pending / ตะกร้ารออนุมัติ */
bg-blue-100 & text-blue-800       /* New / รับเครื่องมารอส่งซ่อม */
bg-purple-100 & text-purple-800   /* Claimed / ส่งเครื่องไปที่ศูนย์เคลม */
bg-orange-100 & text-orange-800   /* Claimed (Received back) / ศูนย์ซ่อมเสร็จ ส่งคืนบริษัท */
bg-green-100 & text-green-800     /* Returned / ส่งเครื่องคืนให้ลูกค้าแล้ว (จบวงจร) */
bg-red-100 & text-red-800         /* ClaimFailed / ยกเลิกเคลม หรือมีปัญหาจัดส่ง (Error state) */
```

## Animations Setup

การโต้ตอบหน้าเว็บขับเคลื่อนด้วยแพ็กเกจ Tailwind Utilities ร่วมกับ SweetAlert:

| Element | Animation Class / Type | Interaction Purpose |
|---------|-----------|-----------|
| **ตระกร้าอนุมัติรับของ** | `animate-pulse`, `animate-shake` | กระตุ้นให้พนักงานเข้ามาดูตะกร้าเพื่อกดยอมรับงานเข้าบริษัท |
| **Notification pop-ups** | `SweetAlert2 (Bounce-in)` | แจ้งเตือนข้อความขยายใหญ่ (Success ✅ หรือ Error ❌) |
| **Modal Enter/Leave** | `animate-fade-in` / `backdrop-blur` | ให้ความรู้สึกนุ่มนวลเวลาคลิกเปิดฟอร์ม ดูเป็นธรรมชาติ |
| **Buttons & Icons** | `hover:shadow-lg`, `active:scale-95` | ตอบสนองต่อเท็กเจอร์คลิกเมาส์ ทำให้ปุ่มแฟบตัวลงเวลาโดนคลิก |
