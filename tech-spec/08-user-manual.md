## ผู้ใช้งานกลุ่มเป้าหมาย (Target Users)

- **พนักงานรับเรื่อง / พยาบาลประสานงาน:** สำหรับการเปิดฟอร์มแจ้งซ่อม เก็บข้อมูลสินค้า และยืนยันการจัดส่งเคลมศูนย์
- **ช่างเทคนิค / แอดมินจัดการสต็อก:** มีอำนาจหน้าที่กดคลิกปุ่ม **"อนุมัติ"** หน้าคลัง เพื่อเปลี่ยนงานที่จองไว้เข้ามาเป็นสถานะรับเข้าระบบบริษัท
- **ผู้บริหาร (Executive):** มุ่งเน้นการดูช่องทาง "Analytics Dashboard" เพื่อตรวจสอบการบริหารความเร็วในการรับ-ส่งบริการ

---

## การเข้าใช้งานระบบ

1. เปิดเบราว์เซอร์บนเครื่องเดสก์ท็อป หรือ แท็บเล็ต (ที่กำลังเชื่อมต่ออินเทอร์เน็ตของโรงพยาบาล/บริษัท)
2. เข้า `http://[IP-Address-ของคอมแอดมิน]:5173`
3. หรือ `http://[ชื่อโดเมน/IP-ของ-Server-ระบบหน้าบ้าน]` (กรณีอัปขึ้น Production)
4. จะพบกับหน้าระบบจัดการตารางคิวงานซ่อมเป็นหน้าหลักแรกสุด

## หน้าตารางงานรับซ่อม (Job / Claim Tracking Table)

เมื่อเข้ามาจะเจอลิสต์ตารางของเครื่องรอส่งซ่อม/คืนลูกค้า โดยมีเมนูเด่นๆ ดังนี้:

- **ปุ่ม + เพิ่มงานใหม่:** อยู่ที่มุมขวาบน ทำหน้าที่สร้างเครื่องแจ้งซ่อม ดึง API ลูกค้ามาได้เลย
- **แถบสีบอกสถานะงานซ่อม:** ช่วยให้มองรู้ว่าเครื่องไหนอยู่ที่ใคร (ดูจากตารางสีฐานข้อมูล) และสามารถกดคลิกตัวหนังสือ **แก้ไข/จัดการเคลม** เพื่อขยับงานไปขั้นตอนต่อไป
- **ตะกร้าอนุมัติ (Shopping Basket):** ตะกร้าที่ขยับกระดิกแปลว่ามีพนักงานร้องขอส่งงานซ่อมเข้ามา ให้แอดมินกดเข้าไปกดยืนยันรับเข้าระบบ
- **ประวัติระบบ (History Logs):** สามารถเปิดตรวจสอบว่าพนักงานคนไหนทำอะไรลบพังไปบ้าง
- **ปุ่มออกรายงาน Excel:** สร้างไฟล์ตารางข้อมูลของงานทุกชิ้นลงในคอมพิวเตอร์ของคุณเพื่อนำไปปริ้นท์ต่อ

### ความหมายของตารางสีสถานะ

| สีพื้นหลัง | สถานะ / ความหมายหลักทางการจัดการ |
|----|-------|
| 🟠 โทนสีเหลือง/ส้ม | **รอแจ้งรับเรื่อง** (แอดมินยังไม่ได้อนุมัติเครื่องเข้าระบบ) |
| 🔵 ฟ้า/น้ำเงิน | **เครื่องรอคิวเคลม** (รอส่งไปศูนย์บริการหลัก) |
| 🟣 ม่วงอ่อน | **ส่งศูนย์เคลม** (ของกำลังอยู่ในศูนย์ซ่อม / อยู่ในกระบวนการประกัน) |
| 🟡 ส้ม/ส้มอิฐ | **รับกลับอยู่ที่บริษัท** (ศูนย์จัดการพัสดุดีดของกลับมาแล้ว กำลังเตรียมส่งคืน) |
| 🟢 เขียว | **ส่งคืนมือลูกค้าแล้ว** (ถือเป็น End-Of-Journey ปิดจ็อบแบบงดงาม) |
| 🔴 แดง | **ตืกลับ/แจ้งเคลมไม่สำเร็จ** (ต้องเริ่มวงจรส่งแก้ไขข้อมูลพัสดุใหม่) |

## หน้า แดชบอร์ดสรุปสถิติผู้บริหาร (Analytics Dashboard)

1. หน้าจอนี้เข้าได้จากเมนูด้านซ้ายล่างสุด หมวด **แดชบอร์ดสรุปสถิติ**
2. แสดงกราฟชาร์ตสีสวยงามของปริมาณงาน (ชิ้นงานผ่านฉลุย, ชิ้นงานค้างในบริษัท, ติดดองในศูนย์เคลม)
3. มีปุ่ม **"⚙️ ตั้งค่า SLA"** สามารถเข้าแก้ไขป้อนตัวเลขเตือนความล่าช้า (เช่น 14 วัน) หากครบ 14 วัน งานใบไหนค้างจะขึ้นเป็นกรอบสีแดงแจ้งเตือนทันที!
4. ออกสรุปยอดเคลมรุ่นฮิต สินค้าพังซ้ำ และรายงาน 5 หน้าเอกสาร ได้ด้วยปุ่มสีเขียวบนแดชบอร์ด **[ โหลดออกรายงาน Excel ]**

## FAQ (คำถามที่พบบ่อยแก้ปัญหาหน้างาน)

**Q: ทำไมค้นหาชื่อพนักงาน/ชื่อลูกค้าด้วยช่องลัดแล้วไม่ยอมเด้งขึ้นมา?**
A: การดึงชื่อดึงมาจาก API SSO หากอินเทอร์เน็ตของ Service Pro ต้นทางขัดข้องจะไม่เด้ง สามารถพิมพ์ชื่อเองกรอกลงไปได้เลยไม่ต้องรอ!

**Q: พนักงานกดจัดส่งคืนลูกค้าไปแล้วผ่านขนส่งรฟท. แต่รฟท.ทำของตีกลับ ต้องทำยังไงให้ระบบอัปเดต?**
A: กดเข้าไปที่งานซ่อมชิ้นนั้น -> กดปุ่มที่หน้าต่าง `แก้ไขการเคลม` เลื่อนหน้าต่างลงล่างสุด แล้วกดติ๊กถูกต้องคำว่า "สินค้าตีกลับ/รับคืนไม่สำเร็จ" 
ระบบจะปรับแถวงานให้เป็น "สีแดง" ให้อัตโนมัติ จากนั้นช่างซ่อมค่อยไปกดปุ่ม **"ย้อนกลับสถานะ"** เพื่อเคลียร์ประวัติให้กลับมาเป็นสีส้มรอจัดส่งรอบสองได้ครับผม

**Q: เว็บไซต์หน้าจอขาว โหลดหมุนตลอดเวลา ทำอย่างไร?**
A: ให้แอดมินไปเช็คฝั่งโปรแกรมหลังบ้านว่าลืมเปิดหรือ API หยุดรันหรือไม่ (ให้แก้ด้วยการใช้เมนู `pm2 restart all`)
